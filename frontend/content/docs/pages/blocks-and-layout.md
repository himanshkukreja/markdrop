## Colour and underline text

Select some text, then choose **A** in the toolbar. The menu has nine text colours and nine backgrounds (highlights). **Default** removes the colour.

- **⌘ ⇧ H** applies the last colour you used again.
- **⌘ U**, or **U** in the toolbar, underlines the selection.

## Colour a whole block

Hover a block, click its handle (**⋮⋮**) and pick a swatch under **Colour**. The top row is text colours and the bottom row is backgrounds.

- A list colours each of its items.
- A callout's background swatch changes the callout's own colour.

With several blocks selected, use **Colour** in the bar at the bottom of the page.

## Link to one block

In a block's menu, choose **Copy link to block**. The link opens the page scrolled to that block, which briefly lights up. This works for readers and for anyone editing.

The link keeps working when the block moves within the page. It stops working if the block is deleted.

## Columns

Type `/2 columns`, `/3 columns`, `/4 columns` or `/5 columns` to add empty columns. To put a block next to another, drag it by its handle to the left or right edge of the other block. A vertical bar shows where it will go.

- Drag the line between two columns to change their widths.
- When you drag the last block out of a column, that column goes away. When only one column is left, its blocks become ordinary blocks again.
- On phones, columns stack one under the other.

## Nest blocks

Press **Tab** on a line to move it under the block above. Nested blocks are indented. Press **⇧ Tab** to bring the line back out.

Under a list item, **Tab** makes the line part of that item. In a table, **Tab** moves to the next cell.

## Select several blocks

- **Esc** selects the block you're in. **⇧ ↑** and **⇧ ↓** then add the blocks above or below.
- **⇧ click** another block to select everything between the two.
- **⌘ A** selects the text of the line. Press it again to select every block.
- Drag from the margin beside the page to draw a box. Every block it touches is selected.

With blocks selected:
- drag any of their handles to move them together;
- press **Delete** to remove them;
- press **⌘ C**, **⌘ X** or **⌘ D** to copy, cut or duplicate them.

The bar at the bottom of the page has the same actions, plus **Turn into** and **Colour**.

## Images

Hover an image to see its tools:
- **Align left, centre or right.**
- **Full screen.** Double-clicking the image does the same. Readers can click any image to see it full screen and download it.
- **Download.**
- **Replace.**
- **Alt text.**
- **Delete.**

Drag the handles on the image's sides to resize it. Type a caption under it. See [Images in pages](/pages/images).

## Tables

Click in a table to see its toolbar. Besides adding and removing rows and columns, it has:
- **Header row**, which turns the first row's styling on or off;
- **Header column**, which styles the first column;
- **Cell colour**, for the selected cells.

To change a column's width, drag the right edge of its header cell.

## Code captions

Type a caption under a code block. Readers see it below the code.

## Buttons

Type `/button` to add a button with blocks under it, such as a to-do. Clicking the button puts a copy of those blocks right after it. This is handy for things you add again and again: a meeting's notes, a task, a checklist. Readers don't see buttons; they only work while you edit.

## Video, audio and files

`/video`, `/audio` and `/file` upload a file from your computer. Each upload becomes its own Markdrop file, kept in the page's workspace and folder, and is embedded in the page. It plays and previews the way every Markdrop file does.

Unlike images, these files keep their own access. A reader who can open the page but not the file sees a locked placeholder. See [Embeds and mentions](/pages/embed-and-mention).

## On a phone

While you edit, a toolbar sits above the keyboard:
- **+** adds a block under this one and opens the block menu;
- **/** opens the block menu where you are;
- **⋮⋮** opens the menu of the block you're in;
- **☑** selects the block;
- **Aa** formats the selected text (bold, italic, strikethrough, code, link) or turns the line into another block;
- **↶** and **↷** undo and redo;
- **⌄** puts the keyboard away.

You can also press and hold a block to open its menu. The format menu and the page's **⋯** menu open as sheets from the bottom of the screen: drag one down, or tap outside it, to close it.
