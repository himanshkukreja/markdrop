Markdrop Guides is free while it's in beta, with every feature on every guide. These limits keep it fair for everyone. When you reach one, the screen you're on says which. Daily limits reset at midnight UTC, monthly ones on the 1st (UTC).

For the plans planned after the beta, see [What does it cost?](/guides/faq#pricing).

## Guides and pages

| | Limit |
| --- | --- |
| Guides in a workspace | 3 (delete one to make room) |
| Personal guides | 3 |
| New guides | 10 a day per person, 20 a day per workspace |
| Pages in a guide | 1,000 |
| One page | 300,000 characters (the editor suggests splitting a page over 3,500 words) |
| Redirects | 1,000 per guide |
| Comments | 300 threads per page, 100 replies per thread |

## Publishing

| | Limit |
| --- | --- |
| Publishes | 30 a day per guide, 50 a day per person across their guides, 100 a day per workspace |
| One publish | 15 MB of pages and settings (split very long pages) |

[Restoring an earlier publish](/guides/publishing#restore-an-earlier-publish) doesn't count. With GitHub's **Publish automatically**, each sync that publishes counts.

## Files and storage

| | Limit |
| --- | --- |
| One image or file in a guide | 25 MB |
| Storage | 2 GB per guide |
| Custom CSS | 20 KB |

Files [embedded from Markdrop](/guides/embed-files) are stored on Markdrop, not in the guide, and follow [Markdrop's file limits](/files/limits).

## AI

| | Limit |
| --- | --- |
| AI uses | 1,000 a month per guide, shared by readers' [Ask AI](/guides/ask-ai), the editor's [AI help](/guides/editor#ask-ai) and the [Fix list's](/guides/fix-list#draft-a-fix) drafted fixes |
| AI help in the editor | 50 uses a day per person; a selection of up to 6,000 characters |
| Suggested Ask AI questions | 5 |

When a guide's AI uses run out, readers get links to ask Claude or ChatGPT with the page attached instead, and AI help says so until the 1st. Nobody is billed.

## Imports and sync

| | Limit |
| --- | --- |
| GitBook imports | 5 a day per person, 10 a day per workspace (they count as new guides too) |
| GitHub imports | 5 a day per person, 10 a day per workspace (they count as new guides too) |
| GitHub syncs | 50 a day per guide |
| OpenAPI file | 5 MB and 1,000 endpoints; [more](/guides/api-reference#limits) |
| Changelog | 500 entries; [more](/guides/changelog#limits) |

## Domains, access and design

| | Limit |
| --- | --- |
| [Your own domains](/guides/custom-domain) | 2 per guide, besides the free address |
| [Private page rules](/guides/private-pages) | 50 per guide, each with up to 1,000 email addresses and 100 email domains |
| Private sections | up to 3 different rules on one page |
| [Design templates](/guides/themes#your-templates) | 50 per workspace |
