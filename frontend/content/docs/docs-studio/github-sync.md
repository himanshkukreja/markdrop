:::warning[Coming soon]
GitHub sync isn't available yet. In the app, **Connect a GitHub repo** on the New docs site form and **GitHub sync** in a site's settings are marked **Coming soon**, and their buttons don't do anything yet.
:::

![The Connect a GitHub repo option on the New docs site form: the GitHub repository panel with a Coming soon badge and a disabled Connect GitHub button.](/docs-assets/docs-studio/github-sync/github-coming-soon.webp)

## What's planned

The app describes it like this:

- You pick a repository and a folder, and your Markdown stays in Git.
- Every push to the main branch publishes the site.
- Pull requests get a preview link.
- Edits made in the browser come back as commits.

## Until then

- **Start blank or from a template**, and write in the [editor](/docs-studio/editor). Its **Markdown** mode shows each page as the Markdown file it is, front matter included, so you can paste in pages from a repository.
- **Coming from GitBook?** [Import the public site](/docs-studio/import-from-gitbook).
- **Want your docs in Git today?** The engine that builds Docs Studio sites can build a folder of Markdown files on your own server. It's early. See [Self-hosting](/docs-studio/self-hosting).
