title: Projects
description: How dashboards, sources and people are organised in Acme.

---

A **project** is where a team's dashboards live. Each project has its own sources, dashboards and members.

| Role | Can do |
| --- | --- |
| Viewer | Read dashboards and get alerts |
| Editor | Build dashboards and add sources |
| Admin | Everything, plus members and billing |

<Accordion title="Can a dashboard live in two projects?">
No. Copy it instead: **Dashboard › Copy to project**. The copy reads the other project's sources.
</Accordion>

<Accordion title="What happens when I delete a project?">
Its dashboards and alerts are deleted after 30 days. Sources stay untouched: Acme never wrote to them.
</Accordion>
