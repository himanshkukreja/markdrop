# Icon

The built-in 24px line icon set, used by every component.

## What you provide

`name` (see the preview for the list), `size`, any SVG prop. Also exported: `ICONS`, the name → path map.

## Look

- 1.8 stroke, round caps and joins, `currentColor`. Sizes 12 / 14 / 16 / 18 / 20 in the components.

## Do / don't

- Add icons to `ICONS` in the same grid and stroke; do not mix in another set.
