# DocumentRow

A document or artifact in a list: icon, title with badges, metadata, Open and an overflow menu.

## What you provide

`title`, `meta`, `href`, `icon`, `badges` (Badge nodes), `actions` MenuItem[].

## Look

- `surface`, `border`, `radius-xl`; 36px `accent-soft` icon tile in `cat-document`; title `body-strong`, meta `caption` in `text-muted`.

## Do / don't

- Meta is one line: link · views · time. Status goes in a sm Badge beside the title.
