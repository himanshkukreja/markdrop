# MarkdownToolbar

Bold, italic, heading, inline code, code block, link and list buttons that wrap the selection in Markdown.

## What you provide

`textareaRef`, `onChange(value)`, `bare` (no background/border, for a tab row).

## Look

- 28px buttons on `surface-inset` above a `border` rule; icons 14px.

## Do / don't

- Keep the editor on `code-bg` in the `code` style.
