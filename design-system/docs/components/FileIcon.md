# FileIcon

A file-type glyph from name and MIME, tinted per family.

## What you provide

`name`, `mime`, `size`. Also exported: `isImage(name, mime)`.

## Look

- Documents `cat-document`, PDFs `danger`, images pink-400, archives `cat-artifact`, video `cat-share`, data `success`, code `cat-sync`, unknown `text-muted`.
