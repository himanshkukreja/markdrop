# Select

A native `<select>` in the Input skin, with a chevron.

## What you provide

`options` [{value, label, disabled}] or children `<option>`s; `invalid`; native props.

## Look

- Native menu for reliability on phones; the chevron is `text-muted`.

## Do / don't

- Prefer RadioGroup for 2–4 options the user should see at once.
