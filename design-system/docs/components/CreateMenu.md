# CreateMenu

The single "Create" entry point: a primary button opening the four creation surfaces.

## What you provide

`defaultOpen` (previews only). Routes are fixed: /new, /upload, /builder, /share.

## Look

- Rich Dropdown items with 32px category tiles: `cat-document`, `cat-artifact`, `cat-builder`, `cat-share` at 12% fill; a warning NEW badge on Artifact.

## Do / don't

- Each item keeps its one-line description — that line is why the menu exists.
