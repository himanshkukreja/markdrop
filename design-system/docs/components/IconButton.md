# IconButton

A square Button for a single icon, with a required accessible label.

## What you provide

`icon` (Icon name), `label` (used for aria-label and title), plus Button's `variant` (default ghost), `size`, `disabled`.

## Look

- 36px square (28 sm, 44 lg); icon at 18px.

## Do / don't

- Wrap in Tooltip when the icon is not universally understood.
