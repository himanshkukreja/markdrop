# Markdrop positioning

Owner: Himanshu Kukreja. Decided 2026-10-13. Applies to the landing hero (the playable world, desktop and mobile), the landing boards, meta tags, OG cards, the brand social card and REVAMP_PLAN §7.1. Headline decided by the founder: **"Drop it. It renders."** Specimens: `Taglines.dc.html` on the revamp canvas.

## The problem this solves

"Paste markdown. Get a link." is a good line, but it describes one feature. It positions Markdrop as a markdown pastebin, and the product is larger than that. The hero has to frame the whole world the visitor is about to play through. It must make two things obvious: **documents** you write, and **files that render** (artifacts).

## The through-line

> Anything you would otherwise paste as raw text or send as an attachment nobody can open becomes a URL that just renders.

There are two pillars, and both are headline-level:

1. **Documents.** Write or paste markdown, including AI-generated write-ups, and get a link that renders it, with Mermaid diagrams and KaTeX math. No account needed.
2. **Artifacts (files that render).** Upload an HTML page, a PDF, a spreadsheet (xlsx or csv), a Word doc, images, video (mp4, mov, webm) or a zipped static site. You get a link that opens it rendered in any browser, with no download and no app. This needs a free account. Files are served from a sandboxed origin and can be protected with a password or an access level.

Everything else extends those two pillars:

- end-to-end encryption;
- the VS Code extension with two-way sync;
- peer-to-peer send;
- workspaces on your own domain;
- the README builder.

The brand promise stays the same: **No login. No friction. Just links.**

## Positioning statement

**For** people who need someone else to *see* what they made: developers, people sharing AI-generated docs with a team, and anyone sending a report or file the other person can't open.

**Markdrop is** the fastest way to turn a document or a file into a link that renders in any browser.

**Unlike** these alternatives:

- doc editors, where the reader has to join a workspace;
- transfer tools, which hand over a download;
- paste sites, which show raw text;

**because** Markdrop renders the finished thing at the link. That covers:

- markdown with diagrams and math;
- HTML pages, PDFs, spreadsheets, Word docs and video;
- whole static sites.

Writing a document needs no account, and opening a link needs no app.

## Alternatives considered

These were the panel's other lockups. They are not in use; keep them for testing or a later revisit. Every one uses "Start writing" as the primary CTA (no account), and every subhead names files that render.

### 1. Docs render. Files open. Just links. (the panel's recommendation)

| Part | Copy |
|---|---|
| Eyebrow | Write it or upload it |
| Subhead | Write or paste markdown and AI write-ups. Upload HTML, PDFs, spreadsheets, Word docs, video or a zipped site. Each one opens in any browser. |
| Secondary CTA | Upload a file |

**Why the panel recommended it:**

- It is the only headline that names both pillars in two beats. "Docs render" covers the documents half and "Files open" covers the artifacts half.
- It closes on the brand promise, so the line sounds like Markdrop and no one else.

**Edit from the shortlist:** the subhead no longer says "nobody could open" (PDFs open fine almost everywhere). The breadth now sits in a plain list.

**Rendering:** two lines at display size: "Docs render. Files open." / "Just links." The final period is in `accent-text`, like the logo dot.

### 3. Attachments break. Links render.

| Part | Copy |
|---|---|

**Rationale:**

- It names a clear enemy, the attachment, which makes it the most artifact-forward option and the sharpest problem frame.

### 4. Every drop becomes a link.

| Part | Copy |

- It turns the brand name into a unit. A "drop" can be a doc, a file, a site or a send, so the line frames all seven features without listing them.

### 5. Write, upload or send. Get a link.

| Part | Copy |
|---|---|

| Subhead | Markdown and AI docs render. So do HTML pages, PDFs, spreadsheets, Word docs, video and zipped sites. Or send files browser to browser. |

**Rationale:**

- It is the direct successor to "Paste markdown. Get a link.", and the only headline whose verbs cover all three modes (write, upload, send). It includes P2P without claiming that sent files render.

## Words

**Use:** link, render / renders, open / opens, write, upload, send, drop (verb and noun), any browser, any device, no download, no app, no account (documents only), the key lives in the link, your own domain.

**Avoid:**

| Avoid | Reason |
|---|---|
| secure, private by default, military-grade | Say exactly what is encrypted and where the key lives |
| "not even we can read it" | Say instead: "Markdrop stores ciphertext it has no key for" |
| never touches a server, serverless, direct, always peer to peer | A relay may forward the bytes, and Markdrop keeps the file name, size and count |
| anything, every format, instantly | Name the formats instead |
| platform, workspace OS, all-in-one, built for | Notion and Linear territory |
| deploy, ship, hosting | Vercel territory |
| transfer, attachment-free, large files | WeTransfer and Dropbox territory |
| paste and share, snippet | Pastebin and Gist territory |
| revolutionary, supercharge, seamless, unleash, AI-powered | Hype words |
| exclamation marks, emoji | Off-voice |

Also: say "no account" only about documents, because artifacts need a free account. Never say "no sign-up" about uploads.
